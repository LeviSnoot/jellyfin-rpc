[![Visitors](https://visitor-badge.laobi.icu/badge?page_id=levisnoot.jellyfin-rpc)](https://github.com/LeviSnoot/jellyfin-rpc)

> [!IMPORTANT]
> This is a fork of [justradical/jellyfin-rpc](https://github.com/justradical/jellyfin-rpc)
> since the original repo has been archived.

Program used to display what you're currently watching on discord.

Jellyfin-RPC uses the API to check what you're currently watching,
this means that the program can run from a server or your computer.
The only requirement is that Discord is open and logged in.
